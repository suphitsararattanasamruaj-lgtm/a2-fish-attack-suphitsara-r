 # Fish Attack

Created by Suphitsara for Creative Coding Assessment 2.

## About the game

Fish Attack is a shark survival game made with Microsoft MakeCode Arcade using Python and Block code.

A player must: 
Control a shark, eat fish, gain points and grow bigger.
Avoid larger creatures until the shark is strong enough to eat them. 
Try to survive the two-minute round and beat your previous high score.

## Controls

- Up arrow: swim up.
- Down arrow: swim down.
- Left arrow: swim left.
- Right arrow: swim right.

You can also use the on-screen directional buttons.

Eating happens automatically when the shark touches a creature it can eat.

## Game rules

- Eat small fish to increase your score.
- As your score increases, your shark grows and can eat larger creatures.
- Touching a creature that is too strong for your shark causes damage.
- Hunger reduces your health over time.
- Eating restores health, up to a maximum of three hearts.
- The round ends when the two-minute timer finishes or your shark loses all its hearts.
- Play again to try to improve your score.

The game also includes an underwater background and sound effects.

## How to open and run the game

You need a web browser and an internet connection.

1. Open [Microsoft MakeCode Arcade](https://arcade.makecode.com/).
2. On the home page, click **Import**.
3. Select **Import URL**.
4. Paste this repository address:

   https://github.com/suphitsararattanasamruaj-lgtm/a2-fish-attack-suphitsara-r

5. Click **Import** and wait for the project to open.
6. Use the game window on the left to play. Click its **Play** button if the game is paused.
7. Click inside the game window and use the arrow keys to control the shark.

This project uses MakeCode's Python environment. It is not a normal desktop Python program, so do not run it using `python main.py`. You do not need to install Python to play it in MakeCode Arcade.

Import the whole project rather than copying only `main.py`, so MakeCode can load the images and other required files.
